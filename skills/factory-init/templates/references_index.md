# 参考資料の索引

過去の資料で引用・流用した資料と、Google Drive の置き場所の、全体の検索用の索引。1 行に 1 つの資料。資料ごとの詳しい記録は、各フォルダの `references.md` と構成案の「流用元」にある。

- 探すとき: 検索より先に `grep -n <語> references_index.md`。
- 書き方: `- [資料名](URL) — 【社内】か【公開】・元の日付。観点: なぜ採用したか・何に使えるかを一言（使った: <フォルダ> p.<ページ>）。注意: <あれば>`
- 資料を仕上げたら、使った資料を足す。すでにある資料なら「使った」にフォルダを足し、観点を直す。
- 【社内】の資料は、顧客向けに使う前に、社外に出せるかを確かめる（`slides-build/reuse.md` の 2）。社内の URL と個人名が入るので、このファイルは納品物に入れない。

## Google Drive の置き場所（顧客のフォルダと、上げた資料）

仕上げた資料を置く先（`deck-practices/drive.md`）。上げた資料は、置いたフォルダの行の下に `- 上げた: <ローカルのフォルダ> → [Drive 上の名前](URL)（初めて上げた日）` で足す。
