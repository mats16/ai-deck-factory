## 書き方
- ファイルの頭で部品は from slides import …、共通の関数と定数は from pages import … で読む。担当のページを 1 枚 1 関数（p<構成案の番号>(d)。例: p06）で書き、それを構成案の順に呼ぶ make(d) も置く（slides.md の 2 の「ページを別のファイルに分けて書く」）。
- 手本と同じ型のページは、手本と同じ関数・同じ呼び方で書く。共通の関数で足りないときも、pages.py を直さずに自分のファイルに関数を書き、返事に書く。
- 構成案の例の仮の語（「〇〇」「TODO」など）は、そのまま写さずに中身に置き換える（dry は lint を回さないので、親が組むまで見つからない）。
- 「書き方の決め」を 1 行ずつ守る。ページをまたぐ数字・言い方は、構成案と書き方の決めにあるものを使う。
- 各ページに出典の行（数字のあるページ）とノートを書く。
- 書いたら <deck-build のフォルダ>/scripts/slides.py lint pages_<担当>.py <デッキの URL> を <資料のフォルダ>/build で回し（組まずに、手元で lint をかける。数秒）、要修正を 0 にする。要確認と組むときの警告は 1 件ずつ見て直すか、残す理由を書く。「（見積もり）」の付いたものは、親が組んで画像で確かめるので、直せないときは理由だけ書く。

## 自分で決めないこと
