# 06 セルを結合した比べる表を書く

`table` のセルに、結合（`colspan`・`rowspan`）・記法・塗りを、説明だけで書けるかを見る。

## 依頼文

```text
deck-build のスキルを使い、社内の勉強会で見せる 1 枚の比べる表を JSON のページで書いてください。
3 つの置き場所（「手元の PC」「共有のファイルサーバー」「クラウドのストレージ」）を比べます。
列は 1 列目が観点、2 列目が項目、そのあとに 3 つの置き場所。見出しは 2 段にし、上の段の「置き場所」は 3 つの置き場所の列にまたがり、「観点」「項目」は 2 段分の高さにする。
観点は「費用」（項目は「始めるとき」「続けるとき」）と「守り」（項目は「バックアップ」「権限」）。観点の名前は、その 2 行にまたがって 1 回だけ書く。
中身: 始めるとき 手元は要らない・サーバーは機器を買う・クラウドは要らない。続けるとき 手元は要らない・サーバーは保守の人・クラウドは使った分。バックアップ 手元は自分で・サーバーは夜間に自動・クラウドは自動で複数の場所。権限 手元はなし・サーバーはフォルダごと・クラウドはファイルごと。
クラウドを勧めるので、その列の見出しを赤の地にし、「自動で複数の場所」は赤の太字にする。「保守の人」のセルには、保守の手順の資料 https://example.com/ops へのリンクを付ける。
Internal/fixture_06/build/ に deck.json と p01.json（表紙は要らない）を書き、slides.py lint deck.json を回して要修正を 0 にしてください。組まないでください。
```

## 見るところ

- `table` で書いている（`frame`・`box`・`text` で格子を組んでいない）。`raw` を書いていない。
- `"header": 2`。1 行目は `{"text": "観点", "rowspan": 2}`・`{"text": "項目", "rowspan": 2}`・`{"text": "置き場所", "colspan": 3}` の 3 つ、2 行目は 3 つの置き場所の 3 つだけ（結合したセルが覆う位置にセルを書いていない）。
- 「費用」「守り」は `"rowspan": 2` で、その下の行は 4 つのセル。
- 勧める列の見出しのセルが `{"text": "クラウドのストレージ", "fill": "RED"}`（文字の色を書いていない）。「自動で複数の場所」が `***自動で複数の場所***`。「保守の人」が `[保守の人](https://example.com/ops)`。
- `slides.py lint` の要修正が 0。
