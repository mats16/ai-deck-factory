# 04 線に名前のある構成図を書く

矢印の名前を `label` に書き、`frame` の図の位置の警告（slides-pages-038）を 0 にできるかを、説明だけで見る。

## 依頼文

```text
slides-build のスキルを使い、社内向けの 1 枚を JSON のページで書いてください。
利用者のアプリが、① 自社のサーバーにログインして要求を送り、② サーバーから通行証を受け取り、③ 通行証を配信のサービスに渡して購読する、という流れの図。アプリは左、サーバーは上の中ほど、配信のサービスは右に置く。3 本の線のそれぞれに番号つきの名前を添える。
Internal/fixture_04/build/ に deck.json と 1 ページ 1 ファイルの JSON を書き、slides.py lint deck.json を回して要修正と組むときの警告を 0 にしてください。組まないでください。
```

## 見るところ

- 線の名前を矢印の `label` に書いている（`text` を x・y で線の近くに置いていない）。
- 矢印の両端を `id` でつないでいる。
- 組むときの警告（線が部品の上を通る、矢じりが 1 点に集まる、部品が一部だけ重なる）が 0。
