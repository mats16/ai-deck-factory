# 07 番号とアイコンの並びを書く

番号やアイコンと文字の並びを、`row` に `num` と `text` を並べずに `list` で書けるかを見る。2026-10-20 に `list` を足したとき（README の「決めたこと」）、番号の円と文字の中心が `row` でずれたページ（深掘りの質問）から作った。

## 依頼文

```text
slides-build のスキルを使い、社内向けの資料「移行の前に聞くこと｜Internal Only」を JSON のページで 2 枚書いてください。
1 枚目は「最初の打ち合わせで聞く 5 つの質問」で、番号の付いた質問を縦に並べる（データの量と増え方、いまの夜間の処理にかかる時間、止めてよい時間帯、
権限の持ち方、監査ログの要否。質問の 1 つは 2 行になる長さにする）。
2 枚目は「移行の前にそろえるもの」で、左右 2 列。左は担当ごとのアイコン（人・データベース・鍵）を付けた 3 項目で、それぞれ見出しと一言の補足。
右はチェックのアイコンを付けた「確かめたこと」の 3 行。
Internal/fixture_07/build/ に deck.json と 1 ページ 1 ファイルの JSON を書き、slides.py lint deck.json を回して要修正を 0 にしてください。組まないでください。
```

## 見るところ

- 要修正が 0 で、組むときの警告（`row` に番号かアイコンと文字を並べた）が出ていない。`raw` を使っていない。
- 1 枚目は `list` 1 つで、番号を手で書いていない（`num` を書かずに 1 から振っている）。
- 2 枚目の左は、項目ごとの `icon` と `head`・`text`。右は list の `icon` を 1 回だけ書いている。
- 印のあるカードを縦に並べて代わりにしていない。
