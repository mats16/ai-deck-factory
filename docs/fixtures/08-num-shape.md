# 08 角丸の番号を書く

角丸の札の番号を、`label` で代用せずに `shape` で書けるかを見る。2026-10-20 に `num`・`list`・`card` に `shape` と、`list` に `digits` を足したとき（README の「決めたこと」）、「01」の札を `label` と座標で書いたページから作った。

## 依頼文

```text
deck-build のスキルを使い、社内向けの資料「勉強会の進め方｜Internal Only」を JSON のページで 2 枚書いてください。
1 枚目は「今日の流れ」で、01 から 05 まで 0 で埋めた番号を角丸の札にして、縦に並べる（受付と環境の確認、全体の説明、手を動かす時間、質疑、アンケート）。
2 枚目は「当日の 3 つの役割」で、番号の付いたカードを横に 3 枚並べる。番号は 1 枚目と同じ角丸の札にする（進行役・講師・補助役と、それぞれ一言の補足）。
Internal/fixture_08/build/ に deck.json と 1 ページ 1 ファイルの JSON を書き、slides.py lint deck.json を回して要修正を 0 にしてください。組まないでください。
```

## 見るところ

- 要修正が 0 で、`raw` を使っていない。
- 1 枚目は `list` 1 つで、`"shape": "round_rectangle"` と `"digits": 2` を書き、項目に番号を手で書いていない。
- 2 枚目は `card` の `num` と `"shape": "round_rectangle"`。
- 番号の代わりに `label` を置いていない。`row` に `num` と文字を並べていない。
