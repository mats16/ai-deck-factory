# 09 同じ形の列と、囲みの中の図を書く

同じ形の列（カードとコードの箱を縦に積んだ列）を、`row` に `stack` を並べずに `grid` で書き、囲みの中の部品を辺から離し、1 本の流れを折れ線にせずに書けるかを見る。2026-10-20 にワークスペースの決まりを大元に移したとき（README の「決めたこと」）、段の上端がそろわない列のページ、囲みの枠とカードの枠が重なったページ、1 本の流れを避けて曲げたページから作った。

## 依頼文

```text
slides-build のスキルを使い、社内向けの資料「設定の 3 つの方式｜Internal Only」を JSON のページで 2 枚書いてください。
1 枚目は「設定ファイルの 3 つの書き方」で、左右に 3 列。どの列も、上に方式の名前と説明のカード（説明の長さは列ごとに違い、1 つは 3 行になる長さ）、
下にその方式の設定の例のコードの箱（2〜3 行）を置く。
2 枚目は「手元から本番までの流れ」で、左に点線の囲み「手元のパソコン」を置き、その中に「書く」「試す」の 2 つの箱を並べる。
囲みの外の右に「レビュー」「本番」の箱を置き、「書く」→「試す」→「レビュー」→「本番」を矢印でつなぐ。
Internal/fixture_09/build/ に deck.json と 1 ページ 1 ファイルの JSON を書き、slides.py lint deck.json を回して要修正を 0 にしてください。組まないでください。
```

## 見るところ

- 要修正が 0 で、組むときの警告（同じ形の stack を並べた、囲みの辺から近い、1 本の流れを折れ線にした）が出ていない。`raw` を使っていない。
- 1 枚目は `grid`（`cols: 3`）にカード 3 つ、コードの箱 3 つの順で並べている。`row` に `stack` を並べていない。カードとコードの箱に `h` を手で書いてそろえていない。
- 2 枚目の囲みの中の箱は、囲みの 4 辺から 0.08 in 以上内側にある。矢印は 1 本も `"route": "bent"` にしていない（箱を同じ行に並べてまっすぐ引いている）。
