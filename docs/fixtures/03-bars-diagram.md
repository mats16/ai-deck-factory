# 03 数字の比べと、枝分かれの構成図を書く

`bars` と、箱につなぐ折れ線の矢印を、説明だけで選べるかを見る。

## 依頼文

```text
deck-build のスキルを使い、社内向けの 2 枚を JSON のページで書いてください。
1 枚目: 問い合わせの件数を窓口ごとに比べる。電話 1,240 件、メール 860 件、チャット 2,310 件、店頭 150 件。チャットを強調する。
2 枚目: 問い合わせの受付から、自動の回答・担当者の対応・開発への連絡の 3 つに分かれる流れの図。
Internal/fixture_03/build/ に deck.json と 1 ページ 1 ファイルの JSON を書き、slides.py lint deck.json を回して要修正を 0 にしてください。組まないでください。
```

## 見るところ

- 1 枚目を `bars` で書き、`hot` は 1 本だけ。凡例や目盛りを自分で組んでいない。
- 2 枚目の枝分かれを `"route": "bent"` の矢印で書き、両端を `id` でつないでいる（座標の `[x, y]` で引いていない）。
